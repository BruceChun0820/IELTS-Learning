# 雅思小作文常用词汇汇总  

## 图表展示

| Vocabulary   | Circumstances    | Examples                                                     |
| ------------ | ---------------- | ------------------------------------------------------------ |
| show         | 最常用，最基础   | The chart **shows** the changes in population between 2000 and 2020. |
| illustrate   | 正式，描述图表   | The graph **illustrates** the proportion of energy consumption by sector. |
| depict       | 正式，地图或图像 | The map **depicts** the layout of the city in 1950.          |
| demonstrate  | 强调“清楚表达”   | The table **demonstrates** a steady rise in sales.           |
| present      | 学术常用，正式   | The diagram **presents** information on the water cycle.     |
| compare      | 对比类           | The two pie charts **compare** sources of income in 1990 and 2010. |
| give data on | 常用替换         | The table **gives data on** the number of visitors to museums. |



## 趋势变化（折线图 / 表格）  

| Vocabulary                                         | Meaning              | Examples                                                     |
| -------------------------------------------------- | -------------------- | ------------------------------------------------------------ |
| increase / rise / go up                            | 上升                 | The number **increased** steadily.                           |
| climb / grow                                       | 上升、增长           | The figure **climbed** gradually.                            |
| soar / surge                                       | 急剧上升             | Sales **soared** in 2015.                                    |
| peak / reach a peak                                | 达到顶点             | It **peaked** at 80%.                                        |
| decrease / decline / drop                          | 下降                 | The rate **declined** slightly.                              |
| fall / go down                                     | 下降                 | The figure **went down** in 2008.                            |
| plummet                                            | 暴跌                 | The price **plummeted** suddenly.                            |
| halve                                              | 腰斩(跌至原本的一半) | The population **halved** to 500,000 over the period.        |
| fluctuate                                          | 波动                 | The data **fluctuated** between 10 and 20.                   |
| level off / stabilize                              | 稳定                 | The growth **leveled off** after 2010.                       |
| remain stable / constant                           | 保持稳定             | The percentage **remained stable**.                          |
| upward / downward trend                            | 上升/下降趋势        | A gradual **downward / upward trend** in unemployment        |
| declined , followed by an increase towards the end | 先跌后涨             | X **declined initially**, **followed** by a modest **increase towards the end**. |

## 比较对比（柱状图 / 表格）  

| Vocabulary                                 | Meaning     | Examples                                     |
| ------------------------------------------ | ----------- | -------------------------------------------- |
| higher / lower than                        | 高于 / 低于 | A was **higher than** B.                     |
| be the highest / lowest                    | 最高 / 最低 | Sydney had the **highest** rate.             |
| account for / represent / make up / occupy | 占比        | Tourism **accounts for** 30%.                |
| compared with / in comparison with         | 与……比较    | **Compared with** 2000, the figure doubled.  |
| be similar to                              | 与……相似    | The figures were **similar to** each other.  |
| be different from                          | 与……不同    | This rate was **different from** the others. |
| by contrast / in contrast                  | 相比之下    | **In contrast**, B decreased.                |

## 数量与比例  

| Vocabulary              | Meaning       | Examples                                               |
| ----------------------- | ------------- | ------------------------------------------------------ |
| proportion / percentage | 比例          | The **proportion** of males rose.                      |
| majority / minority     | 大多数 / 少数 | The **majority** chose option A.                       |
| nearly / approximately  | 接近 / 大约   | **Approximately** 40% of people…                       |
| more than / less than   | 多于 / 少于   | **More than** half of the students…                    |
| twice / three times     | 两倍 / 三倍   | The figure was **twice** as high as…                   |
| a small fraction        | 一小部分      | Only a **small fraction** took the bus.                |
| the bulk of             | 大部分        | The bulk of the population concentrates in the cities. |

| Vocabulary                | Meaning         | Examples                                  |
| ------------------------- | --------------- | ----------------------------------------- |
| demolish / knock down     | 拆除            | The factory was **demolished**.           |
| construct / build / erect | 建造            | A school was **constructed**.             |
| expand / extend / enlarge | 扩建            | The park was **expanded**.                |
| replace / convert into    | 替代 / 改造为   | The houses were **converted into** shops. |

| remain / unchanged        | 保持不变        | The river **remained unchanged**.         |

## 流程图（过程题）  

| Vocabulary               | Meaning     | Examples                                              |
| ------------------------ | ----------- | ----------------------------------------------------- |
| process / procedure      | 过程 / 步骤 | The **process** involves five stages.                 |
| stage / step / phase     | 阶段        | In the first **stage**, water is heated.              |
| begin with / start with  | 从……开始    | The process **begins with** collecting raw materials. |
| followed by              | 接着是      | This is **followed by** filtering.                    |
| end with / finish with   | 以……结束    | The process **ends with** packaging.                  |
| flow into / pass through | 流入 / 经过 | Water **flows into** the tank.                        |

## 常用高级表达（加分词汇）  

| Vocabulary                     | Meaning         | Examples                                    |
| ------------------------------ | --------------- | ------------------------------------------- |
| striking / noticeable / marked | 显著的          | A **striking** change was observed.         |
| dramatic / considerable        | 显著的          | There was a **dramatic** increase in sales. |
| gradual / steady / stable      | 逐渐的 / 稳定的 | A **steady** growth can be seen.            |
| significant / substantial      | 大量的，重要的  | A **significant** proportion…               |
| slight / marginal / negligible | 轻微的          | A **marginal** decrease was recorded.       |

## 时间表达

| Vocabulary                                                  | Meaning              | Examples                                                     |
| ----------------------------------------------------------- | -------------------- | ------------------------------------------------------------ |
| Over the given timeframe / throughout the given period      | 在所给的整个时间段内 | The number of households increased significantly **over the given timeframe**. |
| from A to B                                                 | 从A到B               |                                                              |
| between A and B                                             | 在A和B之间           | There was a gradual decline **between 1990 and 2000**.       |
| over the years A to B                                       | 在A到B年间           |                                                              |
| In the first / latter half of the period                    | 在前 / 后半段        | Car sales remained stable in the first half of the period, but rose sharply **in the latter half**. |
| over time                                                   | 随着时间推移         |                                                              |
| over the following X years / over the course of the decades | 在接下来的若干年里   | The figure showed steady growth **over the course of the decade**. |
